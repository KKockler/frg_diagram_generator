fRG Diagram Editor

A browser editor for functional renormalisation group (fRG) and Feynman diagram figures. It needs JavaScript.

For AI assistants

You can make figures without the browser. A single-file command-line tool (Node ≥ 20) builds them from a JSON spec, and it can draw the whole one-loop flow of any n-point function from just the fields and external legs. FunKit computes the terms and prefactors.

Read the full instructions at llms.txt before you start.

for f in frg.mjs funkit.mjs funkit.wasm; do curl -sSfO https://kkockler.github.io/frg_diagram_generator/$f; done
node frg.mjs flow flow.json -o flow.png -o flow.tex -o flow.frg.json
